# Journal de bord — Veille Technologique

## Semaine 1 — [date]

### Ce que j'ai fait
- Découverte des fondamentaux : IA, Machine Learning, Deep Learning, IA générative, LLM.
- Lecture et adoption de la charte d'usage responsable de l'IA générative.
- Test de prompts, puis amélioration itérative.

### Ce que j'ai appris
- IA ⊃ ML ⊃ DL ⊃ GenAI ; l'IA générative crée du contenu, l'IA classique classe ou prédit.
- Un LLM prédit le mot suivant le plus probable : il produit du texte plausible, pas forcément vrai.
- Hallucinations et biais : toujours vérifier les informations importantes.
- Différence entre LLM, copilot (LLM intégré dans un outil) et agent (enchaîne des actions seul).
- Un bon prompt précise tâche, contexte, public, contraintes et format.

### Difficultés rencontrées
- **Confusion entre IA, ML, DL et GenAI** : au début, je mélangeais les termes. J'ai clarifié avec l'emboîtement IA ⊃ Machine Learning ⊃ Deep Learning ⊃ IA générative ⊃ LLM.
- **Comprendre qu'un LLM ne « sait » pas** : il prédit le mot le plus probable. Sa réponse est donc plausible, mais pas forcément vraie.
- **Repérer les hallucinations** : l'IA répond avec assurance, même quand l'information est fausse (références inventées, chiffres inexacts). Il faut toujours vérifier auprès d'une source fiable.
- **Écrire un prompt précis** : mes premiers prompts étaient trop vagues. Un bon prompt doit préciser la tâche, le contexte, le public, les contraintes et le format.
- **GitHub** : créer le repository, structurer le README.md et faire un commit avec un message clair.
